# pyannote.metrics 4 (numpy>=2). The notebook installs this file with
# `-c constraints.txt` pinning numpy/torch/torchaudio to the preinstalled
# versions, so pip fails loudly instead of silently swapping ABIs.
#
# Every package below supports numpy 2. speechbrain==0.5.16 and scipy==1.14.1
# pins were dropped (old speechbrain conflicts with pyannote.audio >= 3.1).
